# Charmix ホームページ

ビルド不要の静的サイトです。Vercel にこのフォルダをそのまま置けば公開できます。

## よく触るところ
- `data.js` … 商品・ポップアップ出店予定・Instagram URL・名前/顔写真
- `images/` … 商品写真と顔写真を入れる（data.js にファイル名を書く）
- `index.html` … 自己紹介文（About セクション）
- `tokushoho.html` … 特定商取引法に基づく表記（【】を埋める）
- `styles.css` … 色は先頭の `:root` で一括変更

## ネット販売
Stripe で商品ごとに「支払いリンク」を作り、data.js の `stripeLink` に貼ると「購入する」ボタンが出ます。
空のままなら「ポップアップ会場で販売中」と表示されます。

## デザイン候補
`/designs/` に5つの候補があります（キャンディー／雲／アメコミ／洗練ブランド／ステッカー）。
決まったら、そのデザインをトップページ（index.html）にします。
